# 조목조목 v0.3 - 5분 시연 진행안

이 문서는 **예정된 진행 순서**입니다. 실제 녹화 영상, 모델별 구동 성공 기록 또는 실무자 검증 결과가 아닙니다. AI 응답 시간에 따라 시연은 5분을 넘을 수 있습니다. 응답을 기다리는 화면과 실패 메시지를 그대로 보여 주세요.

## 시연 전 준비

- 운영 주소의 설정·진단에서 사용할 모델의 **실제 응답 시험**을 실행합니다. 모델명·확인 시각·성공 또는 실패 결과를 기록합니다.
- 다른 사람의 원문·키가 보이지 않는 브라우저 창을 준비합니다. 가상 예시를 쓰며 실제 기관 규정이라고 소개하지 않습니다.
- 홈의 여비 규칙 예시와 `/impact`의 위원 수 변경 예시를 준비합니다. 예시 응답 모드를 사용할 경우 시작부터 그 사실을 설명합니다.
- 제정·개정의 실제 실행을 입증하려면 각각의 새 입력, 선택 모델, 실제 응답, 담당자 확인, 다운로드 결과를 별도로 기록합니다. 연결 시험 한 번으로 두 흐름의 정상 구동을 입증하지 않습니다.
- 미리 생성한 결과를 여는 경우 "시연 전에 생성한 작업이며 생성 시각과 실행 경로는 여기 있습니다"라고 밝힙니다. 미리 작성한 예시 응답을 실시간 AI 출력처럼 설명하지 않습니다.

| 4:25-5:00 | 사용 기록의 일시정지·종료·CSV와 웹 안내를 보여 줍니다. | "다운로드 뒤 문서 수정까지 포함해 시간을 기록합니다. 수동 수정과 남은 오류도 적습니다. 실제 업무시간 절감은 이 기록으로 별도 실측해야 합니다." |

## 연결 실패가 나왔을 때

1. 오류 메시지와 선택 모델을 보여 주고 정상 구동이라고 설명하지 않습니다.
2. 설정·진단의 실제 응답 시험 결과를 확인합니다. 설정한 키의 값을 화면에 표시하지 않습니다.
3. 원본 그대로의 예시로 준비된 응답을 사용하면 **예시 응답으로 전환했다**고 설명합니다. 일반 원문에 준비된 예시 답변을 대신 붙이지 않습니다.
4. 필요하면 **AI 없이 직접 고치기** 또는 **새 작업으로 AI 다시 실행** 흐름을 보여 줍니다. 새 작업에서 재실행하면 기존 작업을 보존합니다.

## 시연 뒤 남길 기록

시각, 배포 커밋, 입력 구분(가상 예시/새 입력), 선택 모델과 실제 실행 모델, 성공·실패, 실제 응답/예시/문자일치 구분, 다운로드 파일, 복원 결과를 기록합니다. 앱 자체 검증과 네이티브 한글 열기·출력 검증, 실제 담당자의 업무 실측은 서로 구분합니다. 확인하지 않은 항목은 미확인으로 남깁니다.
