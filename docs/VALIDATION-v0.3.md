## 원문 인식

- `제1조`가 중복된 원문에서 정확한 행 번호·문장과 함께 오류가 표시됐다. `작업 시작`을 눌러도 잘못된 구조로 AI 작업이 시작되지 않았다.
- [복잡한 회귀시험용 원문](fixtures/complex-regulation.txt)을 붙여 넣었을 때 **19개 조, 26개 본문·항, 6개 호, 3개 별표·서식**으로 인식했다.
- `제1조의2`, `제10조의12`, 부칙, 별표 2개와 별지 서식 1개가 별개로 인식됐다.
- 원문 수정 후 이전 시작 오류가 남던 화면 문제를 발견해 원문·규정 종류·확인 상태가 바뀌면 이전 오류를 지우도록 수정했다.
- 브라우저 자동화의 파일 선택 함수가 응답하지 않아, 운영 화면의 파일 업로드 및 파일 선택을 통한 복원은 완료하지 못했다. 이를 앱의 업로드 성공 또는 실패로 판정하지 않았다. HWPX/TXT 추출과 복원 함수의 자동검증은 별도로 통과했다.

## 실제 AI 영향 분석부터 문서 다운로드까지

**가상 검증 자료**를 사용했다. 예시 버튼은 입력만 채우며, 영향 분석·개정 제안·이유서는 실제 AI에 요청했다.

| 단계 | 운영 앱에서 확인한 결과 |
| --- | --- |
| 상위기준 입력 | 제10조 위원 정수 30명 이내 → 20명 이내 |
| 기관 규정 입력 | 3개 조. 제2조가 상위기준 제10조를 직접 인용 |
| 실제 영향 분석 | Gemma `gemma-4-31b-it`, 표시 시간 9.0초, `impact_review@v1.3`, 후보 제2조 1개 |
| 인용 대조 | 기관 원문과 상위기준 개정 전·후 인용이 입력 원문과 일치 |
| 담당자 선택 | 제2조를 선택해 기존 개정 작업으로 연결 |
| 실제 개정 제안 | 같은 모델, 표시 시간 5.1초. `30명 이내 → 20명 이내` 1건 |
| 전체 작업 기록 | 6.2초. 가상 법령은 공식 원문 조회 실패로 표시하고 사용자 제공 근거 2건 유지 |
| 수락·점검 | 제2조 변경 1건 수락, 새 형식 오류 0건 |
| 이유서 | 실제 AI 작성. 검토 확인 전 다운로드 비활성화, 확인 후 활성화 |
| 산출물 | HWPX·DOCX 6종씩 실제 ZIP 다운로드 완료 |

근거 창에는 시행일, 자료 기준일, 조회·등록 시각, SHA-256, 보존 원문이 표시된다. 사용자 제공 자료를 공식 확인이 끝난 근거로 표시하지 않았다. 원문과 근거의 실제 해시는 첨부 검증 JSON에 기록했다.

## 실제 파일과 복원 검증

- [실제 운영 문서 ZIP](validation/v3-impact-export.zip): 내려받은 원본을 그대로 보존했다.
- [문서 교차검증 결과](validation/v3-impact-export.json): 압축·XML, 개정안·대비표·이유서·전문·점검표, 근거와 백업을 대조했다.
- 제1조·제3조는 그대로이고 제2조만 20명으로 변경됐다. 대비표에는 현행 30명/개정 20명과 밑줄이 포함됐다.
- [실제 보관파일 복원 검증](validation/v3-backup-restore.json): 운영 ZIP 안의 백업을 실제 `parseProjectBackup`·`restoreProjectBackup`에 넣어 새 ID, 원본 보존, 수락 상태, 근거 연결, 이유서 확인 상태, 일시정지 시간을 확인했다. 저장은 메모리 콜백으로 수행했으며 브라우저 파일 선택·IndexedDB 저장 검증으로 주장하지 않는다.
- 후속 보강은 변경 제안·제정 조문·비교 제안이 보관파일에 없는 근거를 참조하면 위치와 누락 ID를 알려 주고 복원을 거부한다. 빈 근거 배열과 근거를 지정하지 않은 정상 작업은 허용한다.
- 문서 검사 범위는 압축 패키지·XML·내용·해시다. 한컴오피스나 Microsoft Word에서 직접 열어 편집·인쇄한 결과는 아니다.

## 사용 기록과 안내서

- 시작·일시정지·종료·문서 다운로드 횟수·CSV 다운로드를 운영 화면에서 확인했다.
- [검증용 CSV](validation/v3-pilot-qa.csv): `QA-AI / V03-IMPACT-R2`, 가상 자료를 이용한 자동화 기능 검증임을 명시했다. 기존 방식 시간과 만족도는 임의로 입력하지 않았다.
- ZIP 안 기록은 다운로드 시점의 일시정지 상태이며, 별도 CSV는 이후 종료한 상태다. 기록값은 직원 실증이나 업무시간 절감의 증거가 아니다.
- `/guide`에서 4쪽 안내서 PDF를 실제로 내려받아 저장소 파일과 바이트 단위 일치를 확인했다. 101,949바이트, SHA-256 `04a1dcd40f299f1ac9fc23379b103c13153b6bc278df9d380c4deb39d5b9daf9`.
- 5분 시연 대본도 준비했다. 대본은 녹화된 시연 영상이 아니다.
