# v0.7 다섯 역할의 검토와 채택 결정

기준일: 2026-10-26. 개발 과정에서 총괄 통합을 포함한 다섯 역할이 병렬 검토와 상호 피드백을 수행했다. 앱이 화면을 열 때마다 다섯 개 외부 AI를 호출하는 구조를 추가한 것은 아니다.

| 역할 | 담당 | 채택한 결정 |
|---|---|---|
| 총괄·홈 통합 | 사용자 요구, 홈 흐름, 기존 업무 연결, 배포 | 큰 조목이 옆에 두 시작 행동을 배치하고 문서 예시는 다음 영역으로 이동 |
| 캐릭터·모션 | 기존 조항호목·연필 외형, 표정과 SVG·CSS 동작 | 6종 표정, 수동 선택과 자동 전환, 작은 업무 화면의 단발 동작 |
| 입안 자료 감사 | 원본 5종·출처 안내·실제 코드 대조 | 누락 자료보다 위임·부칙 판단의 업무 연결을 우선 기획 |
| 독립 평가 | 공식 배점, 구현 증거, 미확인 효과 | 캐릭터의 가점은 사용성 1점 범위, 법제 정확도와 실무 효과 실증은 별도 |
| 독립 품질 검수 | 접근성, 상태 표시, 작은 화면, 문서 영향 | 동작 버튼 의미·색 대비·모바일 선택자·반영 이후 변경 표정 수정 |

## 피드백 후 변경

- 동작을 켜고 끄는 버튼은 다음 행동을 이름으로 나타내고, 표정 버튼만 선택 상태를 표시한다.
- 말풍선은 일반 흐름에 넣어 줄 수가 늘어도 캐릭터와 겹치지 않게 한다.
- 홈 자동 전환은 8초 간격이며 직접 표정을 고르면 멈춘다. 별도 정지는 몸짓과 순환을 함께 멈춘다.
- 동작 줄이기 설정과 숨겨진 탭에서는 반복을 정지한다. 자동 말풍선 변경을 반복 낭독하지 않는다.
- 검토 반영 시점의 본문과 현재 본문이 같을 때만 반영 표정을 쓴다. 이후 수동 수정은 추가 확인 상태다.
- 핵심 자료 5종과 추가 안내 TXT를 구분하고 모든 원본 다운로드를 유지한다.
- 자료에서 찾은 기능 공백과 현재 구현을 분리한다. 법제 기준을 한 번에 모두 자동 확정하려 하지 않고 근거표·적용 관계·요청서로 발전시키는 계획을 세운다.

자세한 증거는 [자료 재검토](v07-manual-audit.md), [독립 평가](v07-independent-scorecard.md), [독립 UI 검수](v07-ui-qa.md), [통합 검증](../VALIDATION-v0.7.md)에 있다.
