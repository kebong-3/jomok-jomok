## 기존 업무 처리표

`AddendaSpec.transitions`에 신청·계약/위탁·위원/임기·위반행위/제재·서식/시스템·그 밖의 업무를 저장한다. 본문 키워드는 관련 조문 후보를 제시할 뿐, 실제 기존 대상이나 법 적용 결론·부칙 문장을 채우지 않는다.

기록은 다음 항목을 가진다.

- 관련 본칙 조문, 기존 대상, 적용을 나누는 기준 사건과 날짜
- 종전 규정·개정 규정·별도 기준·미확인 중 담당자의 판단
- 시행 준비·적용례·특례·경과조치 중 작성 방식
- 확인한 개별 근거, 검토 메모, 조문 제목과 담당자 작성 본문
- 확인 전·확인 완료·해당 없음 상태 및 확인 당시 초안 지문

필수값이 없거나 날짜가 잘못됐거나 연결 조문이 없으면 ‘확인 완료’라고 저장되어 있어도 부칙에 넣지 않는다. 삭제된 조문은 ‘종전의 제○조’로 명시한다. 해당 없음에는 실제 대상·기준 사건·관련 조문과 이유가 필요하며, 그 판단을 조문으로 출력하지 않는다.

초안 지문은 제목·규정 종류·본칙·별표/서식·종전 부칙·시행일·기존 단일 경과조치 입력을 포함한다. 검토 기록 자체는 제외하므로 저장만으로 무한 재확인이 생기지 않는다. 본문이나 시행일이 바뀌면 이전 결정은 보존하면서 현재 부칙 출력에서 제외한다. 미확인·입력 미완료·본문 변경 후 재확인 사항은 별도 검토 기록으로 남긴다.

## 일몰 조문

`deadlineReview`는 기관 유형, 적용/제외 여부, 재검토기한/유효기간 유형, 적용 근거, 담당자 작성 문장, 확인 지문을 가진다. 법정 기한·날짜·주체를 임의로 생성하지 않는다. 지방자치단체도 자체 근거를 확인해 기록할 수 있으나 중앙행정기관 기준을 자동 적용하지 않는다.

기존 `reviewDeadline: true`는 잃어버리지 않고 ‘일몰 적용 여부를 검토해 달라는 이전 선택’으로 취급한다. 이 값만으로 부칙이나 본칙을 생성하지 않는다. 확인한 문장에 대해 ‘검토한 조문을 본칙 마지막에 추가’를 누르면 다음과 같이 작동한다.

1. 화면이 열릴 때의 초안 지문과 현재 프로젝트를 다시 계산해 비교한다. 다르면 반영하지 않는다.
2. 같은 일몰 조문이 이미 있으면 중복 추가하지 않는다. 폐지 작업에는 새 본칙을 추가하지 않는다.
3. 제정은 담당자 작성 조문으로 체계 끝에 추가한다. 전부개정은 별표·서식 앞에 추가하고 전부개정 본문 확인을 해제한다.
4. 일부개정은 원문 조문을 기준으로 신설 연산을 만든 뒤 실제 결과를 다시 계산한다. 마지막 위치와 다른 조문·별표의 지문이 유지되는 경우만 반영한다.
5. 자신이 명시적으로 추가한 일몰 조문의 확인 지문은 새 본문에 연결한다. 다른 기존 업무 판단은 새 본문에서 다시 확인해야 한다.

유효기간과 재검토기한은 효과가 다르다. 이번 구현은 그 선택과 담당자의 문장을 기록·배치하는 지원이며, 일몰제의 적용 여부나 특정 기한의 적법성을 독립적으로 검증하는 법률 판단 엔진은 아니다.

## 종전 부칙과 출력 기록

전부개정·폐지에서 원문의 종전 부칙을 보여 주고 ‘계속 필요한 내용 있음 / 새 적용 관계로 정비 필요 / 없음 / 미확인’과 판단 이유를 저장한다. 지문에는 원문 제목·종류·종전 부칙과 개정 방식이 들어가므로 전부개정에서 폐지로 바꾸면 같은 기록을 그대로 확인 완료로 쓰지 않는다.

`transitionReviewText`는 현재 상태를 한국어로 출력한다. 종전 원문과 개정 방식을 전달받으면 종전 부칙 확인 지문의 일치 여부도 출력한다. 전달받지 못하면 ‘별도 대조 필요’로 남겨 확인한 것으로 표시하지 않는다.

## 검증

`tests/transition-review.test.ts` 19개와 변경 요구를 반영한 `tests/engine-regressions.test.ts` 13개, 총 32개가 통과했다.

검증 내용은 확인 전/미완성 판단의 출력 제외, 네 종류 입력 변경 후 재확인, 부칙 순서, 해당 없음 기록, 잘못된 날짜·없는 조문·잘못된 구조, 삭제 조문 구분, 실제 수락 변경과의 일치, 구버전 체크 호환, 일몰 유형·기관 구분, 기존 신설 조문이 있는 일부개정의 마지막 배치, 반영 직전 변경 거부, 별지 보존, 제정·폐지 구분, 전부개정과 폐지 간 종전 부칙 재확인, 한국어 출력과 일몰 자기 확인 지문 갱신이다.

이는 소프트웨어 회귀 검증이다. 실제 기관 사건에 대한 법제 담당자의 독립 판단, 한컴 한글 편집·인쇄, 사용자 업무시간 비교 실증을 대신하지 않는다.
