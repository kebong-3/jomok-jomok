# 조목조목 v0.7 검증 기록

기준일: 2026-10-26. 이번 범위는 큰 홈 조목이, 표정·움직임·정지 기능, 친숙한 시작 안내, 현재 상태에 맞는 업무 화면 표정, 핵심 5종 자료 재검토와 독립 평가다. 이전 실제 AI 호출·문서 다운로드 검증은 [v0.6 기록](VALIDATION-v0.6.md)에 있으며 이번에 다시 호출한 것으로 계산하지 않는다.

## 구현

| 요구 | 반영 내용 | 확인할 동작 |
|---|---|---|
| 큰 홈 캐릭터 | 파스텔 홈, 큰 조목이, 새 규정·기존 규정 시작 버튼 | 캐릭터와 시작 행동을 함께 볼 수 있음 |
| 다양한 표정 | 인사·미소·활짝 웃음·생각·응원·다정함의 눈·입·팔·장식 분기 | 선택한 표정과 화면 제목·SVG가 일치 |
| 움직임과 제어 | 눈 깜빡임·손 인사·생각·웃음·응원, 8초 표정 순환 | 수동 선택 시 순환 중지, 움직임 중지·재개 |
| 집중과 접근성 | 동작 줄이기 CSS와 미디어 설정, 숨겨진 탭 중지, 버튼 이름·선택 상태 | 반복 알림을 만들지 않으며 키보드로 선택 가능 |
| 실제 업무와 연결 | 시작·AI 진행·다음 행동·검토 반영·파일 준비에 표정 연결 | 반영 이후 본문이 달라지면 다시 확인하는 표정·설명 |
| 자료 수 정확히 안내 | 핵심 PDF 4권과 HWPX 1종, 추가 출처 안내 TXT를 구분 | 5종 자료 표시와 전체 6개 원본 다운로드 유지 |

홈 말풍선은 일반 문서 흐름에 배치하여 글자가 여러 줄이 되어도 캐릭터와 겹치지 않도록 했다. 작은 업무용 캐릭터는 기본 한 번만 움직이며, 실제 AI 처리 중에는 반복한다. SVG·CSS이므로 캐릭터 표정 변경 자체에는 AI 호출이 없다. 정식 문서 생성 경로는 캐릭터 컴포넌트를 포함하지 않는다.

## 운영 배포와 실제 조작 기록

구현 커밋 `4db6db420e99aa786d915a3b38395c2c5b0d10b6`를 Vercel `kevin-jeong/jomokjomok-law`에 배포했다. 공개 진단에서 **v0.7.0 · 4db6db4 · icn1**, 참고자료 색인 정상 상태를 확인했다. GitHub Actions 실행 `40346148450`의 설치·전체 검사·운영 빌드·타입 검사가 모두 성공했다. 운영 확인은 2026-10-26 UTC / 2026-10-27 한국 시간이다. [기계 판독 기록](validation/v07-browser-production.json)

- 1363×936 화면에서 큰 캐릭터와 두 시작 행동이 함께 보이고 가로 넘침이 없었다. 캐릭터 SVG 크기는 234×248.625 CSS px였다.
- 여섯 표정 버튼을 각각 눌러 선택 상태, 캐릭터 이름, 서로 다른 동작 CSS가 바뀌는 것을 확인했다. 웃음·인사·생각 표정은 화면으로도 확인했다.
- 수동 선택 후 자동 전환이 꺼졌고, 다시 켜자 다른 표정으로 바뀌었다. 정지하면 `data-motion=none`, 계산된 애니메이션 이름도 `none`으로 바뀌었다. 재개 버튼도 확인했다.
- Enter 키로 미소 표정을 선택했다. 새 규정 만들기 링크를 눌러 실제 제정 입력 화면으로 이동했다.
- 자료실은 핵심 5종과 추가 안내 1개를 구분하며 6개 원본 다운로드를 유지했다. 의견제시 요청서 HWPX를 실제 내려받아 원본과 바이트 단위로 일치하는 것을 확인했다.
- 기존 가상 작업의 7개 조문과 검토 기록을 불러왔다. 반영 상태에서는 응원 표정, 이후 제7조를 시험 편집하면 다정함 표정과 ‘수정 반영 이후 초안이 다시 바뀌었습니다’ 안내가 나타났다. 시험 문장은 정확히 원래 값으로 복원했다.
- 제정안 DOCX를 실제 내려받아 ZIP·12개 XML을 검사했다. 검토용 표시와 복원한 조문을 확인했고 조목이 UI는 문서에 들어 있지 않았다. 파일 준비 화면의 응원 캐릭터는 한 번 움직이도록 표시됐다. [다운로드 검사](validation/v07-downloads.json)

## 자료 재검토와 평가 범위

[자료 재검토·후속 기획](research/v07-manual-audit.md), [원본 대조 결과](validation/v07-manual-audit.json), [독립 평가표](research/v07-independent-scorecard.md)를 함께 제공한다. 핵심 5종과 추가 안내의 원본 지문은 일치했다. 1,997쪽을 모두 이번에 정독하거나 모델을 재학습했다고 주장하지 않는다.

조문별 근거표, 대상별 부칙 판단, 공식 요청서 작성 완료본, 전부개정·폐지, 기관 규정 묶음의 영향 관리 등은 후속 기획이다. 이번 화면 변경의 구현 점수에 포함하지 않는다. 재검토기한 기본 위치 등 매뉴얼과 기존 생성 로직의 차이도 보고서에 남겼으며 이번에는 문서 생성 엔진을 변경하지 않았다.

공식 평가 배점과 개발자의 자체 점수는 구분한다. 운영 데스크톱 UI 확인을 반영한 자체 평가 점수는 v0.7 **83점(32/26/25)**이다. v0.6의 82점에서 사용성에 1점을 추가한 판단이며 공식 심사 결과가 아니다. 실제 주무관의 업무효과, 독립 법제 사례 평가, 한컴 네이티브 편집·저장, 두 번째 기관의 설치·이관 실증은 이번 검수 범위에 없다.
