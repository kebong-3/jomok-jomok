## 자동 검사

## 운영 브라우저 기록

배포 전 동일한 가상 작업에서 Gemma가 제정 체계 7개 조를 18.0초, 조문 본문을 40.7초에 생성했다. 담당자 확인 버튼은 누르지 않았다. 문서 화면의 개별 HWPX·DOCX 버튼이 비활성화되는 기존 현상을 재현했다.

v0.6 적용 커밋 `a115dac1892189d16cf1b55ca85f65c37827f194`를 배포한 뒤 같은 브라우저 작업을 새로고침했다. Vercel `kevin-jeong/jomokjomok-law` 배포 `AidTjnb4hxtnGjNxq8coERYbrfdT` 성공, 공개 진단의 v0.6.0·커밋·icn1 일치를 확인했다. [운영 UI 실측](validation/v06-browser-production.json)

1. 조문 7개의 담당자 확인 상태를 유지한 채 개별 버튼이 활성화됐다. 제정안과 입법예고문을 각각 HWPX·DOCX로 실제 다운로드했다. 총 4개 파일의 ZIP, 전체 XML, HWPX mimetype 배치와 검토용 표시를 확인했다. [파일 검사](validation/v06-live-downloads.json)
2. 입법예고문 공고번호를 `검증01호`에서 `검증02호`로 바꾸자 이전 저장 링크가 사라졌다. 새로 받은 DOCX에는 변경한 번호와 담당부서가 들어 있었다.
3. 제7조에 문장 검증용으로 직접 입력한 ‘당해’ 표현을 알기 쉬운 문장 모드로 검토했다. 실제 응답은 **GPT-OSS 120B · Groq, 33.7초**였다. 연결 기록에는 Gemma에서 대체 연결한 사실도 남았다. 검색 원문과 맞지 않은 인용·제안 1건을 제외한 안내가 표시됐다.
4. 남은 수정안 1건을 체크하고 반영했다. 제7조의 ‘당해’가 ‘해당’으로 바뀌고 다른 6개 조문은 문자열까지 같았다. 되돌리기로 7개 본문 전체가 이전과 같아졌고, 다시 반영한 뒤 새로고침해 본문·검토 결과·근거·반영 기록이 유지됨을 확인했다.
5. 제7조를 시험용으로 직접 편집한 결과를 제외한 나머지 6개 AI 조문은 여전히 미확인이다. 검토 수정 반영이 다른 조문의 확인 완료를 대신하지 않았다. 실제 받은 [작업 보관파일](validation/v06-live-work-backup.json)에 검토 결과와 복구 정보도 포함됐다.
6. 실사용에서 반영 뒤에도 비교표가 ‘현재 초안’이라고 표시하면 과거 문장을 현재 내용으로 오해할 수 있어, 최종 문구를 **수정 전 문장 / 수정 제안 문장**으로 명료화했다.

## 확인 범위

현재 기능은 긴 작업을 외부 서버 큐에서 무기한 실행하는 구조가 아니다. Vercel·AI 제공자의 한도는 별개이며 요금제나 환경변수를 임의 변경하지 않았다. 문장 수정은 정확한 치환만 자동 반영하고 조 번호·부칙·별표 등 구조 변경은 담당자가 직접 검토한다. 인용 일치와 파일 구조 검사는 법률적 적합성 심사를 대신하지 않는다.

검수 환경에 한컴 한글이 없으므로 HWPX의 한컴 네이티브 열기·다시 저장·인쇄를 검증했다고 주장하지 않는다. [기존 매뉴얼 서식 대응과 문서 검수](research/v05-form-mapping.md)를 함께 참고한다.
